# OnlineTV

Автоматический IPTV плейлист с ежечасным обновлением.

## Ссылка для плеера

https://raw.githubusercontent.com/SlayerHasher/OnlineTV/main/playlist.m3u

## Особенности

- ✅ **Только русские каналы** — фильтрация по кириллице и ключевым словам
- ✅ **Нормальные категории** — стандартные русские категории (Новости, Фильмы, Сериалы, Спорт, Детские, Музыка, Познавательные, Развлекательные и др.)
- ✅ **Умная дедупликация** — удаление дублей по названию и URL с приоритетом источников
- ✅ **EPG поддержка** — сохранение tvg-id для телепрограммы (217 каналов)
- ✅ **Чистые логотипы** — автоматическое удаление некорректных data:image логотипов
- ✅ **Проверка доступности** — HTTP HEAD проверка работоспособности стримов
- ✅ **Автоматическое обновление** — каждый час через GitHub Actions

## Конфигурация

Настройки находятся в `config.json`:

```json
{
    "russian_only": true,           // Только русские каналы
    "standard_categories": true,    // Стандартные категории
    "require_epg": false,           // Оставить только каналы с EPG (tvg-id)
    "cleanup_invalid_logos": true,  // Удалять некорректные логотипы
    "check_stream": true,           // Проверять доступность стримов
    "exclude_keywords": ["18+", ...] // Исключить по ключевым словам
}
```

## Ручной запуск

Actions → Update Playlist → Run workflow
